# Data dictionary

Generated by `make dictionary` from the comments in the database (migration 0023).
Do not edit it by hand: change the comment in a new migration and generate it again.
A view column without its own comment shows the description of the column it passes on.

## meta

The catalogue: sources, their snapshots, pipeline runs, migrations and exit-check reports.

### meta.check_result (table)

What one check found for one layer and source: how many rows were bad out of how many.

| column | type | null | description |
| --- | --- | --- | --- |
| `check_result_id` | bigint | no | Identifier of the result. |
| `check_run_id` | bigint | no | The run the result belongs to. |
| `layer` | text | no | The layer that was checked, for example parcel or wind_unit. |
| `source_id` | text | no | The source within the layer; - for a result about the whole layer. |
| `check_name` | text | no | Name of the check, for example geometry_invalid, or flag:<name> for a quality flag. |
| `severity` | text | no | ok (nothing found), info, warning (reported, never blocks) or error (the exit check fails). |
| `bad` | bigint | no | Number of rows (or sources, for a source-level check) that failed the check. |
| `total` | bigint | no | Number of rows (or 1, for a source-level check) that were checked. |
| `message` | text | no | What was found, in words; empty when nothing was found. |
